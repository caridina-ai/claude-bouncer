# claude-bouncer 暫時阻擋其它的 claude session 以保留額度給 patron

## 使用場景

我有一個操盤的 claude session，每天 8:30 到 13:30 操盤時，要暫時擋住其它的 claude sessions 不要消耗額度，而且要保留週額度 w% 給它

我預定的做法是仿照這台電腦上的 D:\projects\continue-claude 的 -export 做法，把共用資訊即設定檔放在 X:\，X:\ 是每台電腦都一致設定的網路磁碟機，而暫時阻擋的部份仿照 D:\projects\stall-claude 的方式，掛 preToolUse hook，如果呼叫的 claude session 需要被阻擋，就由這個 CLI sleep 到適當的時間解除

## 設定檔

設定檔只要有以下四個欄位

1. patron 的 ID，請偵測比對 session name

2. 每日開始獨佔的時間，例如 8:30

3. 每日結束獨佔的時間，例如 13:30

4. 每日須保留給它的週額度 w%

## 何時阻擋，擋到何時

1. 在當天 8:30 到 13:30 的獨佔期間，session ID 符合 patron ID 者不阻擋；session ID 不符合者 sleep 到 13:30

2. 獨佔期間以外的時間，不管是否符合 patron ID，一律先計算「到週額度重置之前，還需要保留多少 w% x N」，如果還足夠就一律放行；如果會造成保留額度不足，則不論 session ID 一律 sleep 到下一次收盤的時間

因為操盤的 claude session 在收盤以後，還會做一些研究工作，繼續消耗額度。有了這套阻擋機制，則除了可以避免其它 session 把它的額度耗完之外，也可以阻止它自己做研究時把自己的額度耗完

sleep 到下一次收盤時間，是因為當日操盤可能用不到 w%，因此收盤以後再重新計算 remain - w% x N 時，可能會算出還有額度，那它們就還有機會再執行一段時間

例外：符合 patron ID 者只 sleep 到下一次開盤。因為開盤後依第 1 條它不應被阻擋，若照樣 sleep 到收盤，它就會睡過整個操盤時段，該上班時沒辦法上班

## 週末不獨佔

我的操盤程式只有週一到週五才需要獨佔，所以：

1. 週六、週日沒有獨佔期間，整天都只依上述第 2 條判斷是否阻擋

2. 計算 w% x N 時，N 只算週一到週五的獨佔期間，週末不算在內

3. 「下一次收盤的時間」也跳過週末，例如週五收盤後若保留額度不足，就 sleep 到下週一收盤

設定檔仍然只有原本的四個欄位，週一到週五直接內建

## 具唯讀特性

由以上功能描述可知，這個 CLI 只會讀取設定檔、sleep，完全不需要寫檔案的權限
